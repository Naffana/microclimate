# Оптимизация производительности графиков при большом диапазоне дат

## Проблема
При выборе диапазона в несколько дней график тормозит из-за большого количества SVG-точек (~8600 на график). Recharts рендерит каждую точку как SVG-элемент.

## Решение: Даунсемплинг данных
Если количество точек > порога, агрегировать данные в более крупные интервалы.

### Изменения

#### 1. `app/lib/actions.ts` — добавить функцию даунсемплинга
Добавить `downsample(data, maxPoints)` — если точек больше `maxPoints`, разбить на равные.bucket'ы и взять среднее значение в каждом.

```ts
export function downsample(data: CombinedPoint[], devices: DeviceId[], maxPoints: number = 500): CombinedPoint[] {
  if (data.length <= maxPoints) return data;
  const step = Math.ceil(data.length / maxPoints);
  const result: CombinedPoint[] = [];
  for (let i = 0; i < data.length; i += step) {
    const chunk = data.slice(i, i + step);
    const avg: any = { ts: chunk[0].ts, time: chunk[0].time };
    for (const d of devices) {
      const vals = chunk.map(c => (c as any)[d]).filter(v => typeof v === 'number');
      avg[d] = vals.length > 0 ? vals.reduce((a: number, b: number) => a + b, 0) / vals.length : null;
    }
    result.push(avg);
  }
  return result;
}
```

#### 2. `app/ui/area/Area.tsx` — применить даунсемплинг
В `SimpleAreaChart`, после `combineByMinute`, применять `downsample` если точек > 500:

```ts
const { devices, combined: rawCombined } = React.useMemo(() => combineByMinute(data), [data]);

const { combined } = React.useMemo(
  () => ({ combined: downsample(rawCombined, devices, 500) }),
  [rawCombined, devices]
);
```

#### 3. `app/ui/area/Area.tsx` — оптимизация `findClosest`
Заменить линейный поиск на бинарный поиск (данные уже отсортированы по `ts`):

```ts
const findClosest = React.useCallback((ts: number): CombinedPoint | null => {
  if (combined.length === 0) return null;
  let lo = 0, hi = combined.length - 1;
  while (lo < hi) {
    const mid = (lo + hi) >> 1;
    if (combined[mid].ts < ts) lo = mid + 1;
    else hi = mid;
  }
  if (lo > 0 && Math.abs(combined[lo - 1].ts - ts) < Math.abs(combined[lo].ts - ts)) {
    return combined[lo - 1];
  }
  return combined[lo];
}, [combined]);
```

### Верификация
1. Выбрать диапазон в 7 дней → график должен загружаться быстро
2. Зум/пан/тултип должны работать плавно
3. При малых диапазонах (1 день) количество точек не должно уменьшаться
